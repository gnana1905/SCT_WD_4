# To-Do List Application

A clean, modern, and responsive To-Do List web application built with vanilla HTML, CSS, and JavaScript.

## Features
- **Task Management**: Add, edit, delete, and mark tasks as active or completed.
- **Due Dates & Times**: Schedule tasks with date and time selectors.
- **Search & Filtering**: Real-time task search and instant filtering by All, Pending, and Completed with live counters.
- **Local Persistence**: Automatically saves tasks and theme preference to browser `localStorage`.
- **Light & Dark Themes**: Sleek dark mode toggle with smooth visual transitions.
- **Responsive Design**: Clean and fully usable layout across mobile, tablet, and desktop devices.
- **Accessible & Clean UI**: Minimalist design with smooth hover states, formatted badges, and clear empty states.

## Project Structure
```text
├── index.html    # Application structure and semantic markup
├── style.css     # Clean design tokens, layouts, and dark theme
├── script.js     # Task state handling, storage, and event logic
└── README.md     # Documentation
```

## How to Run
Simply open `index.html` in any modern web browser or serve it using any local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve
```
